# Epic {epic_num} Retrospective

## Mission

Run a retrospective after Epic {epic_num} completion to review success, extract lessons learned, and prepare for the next epic.

## Process

### 1. Epic Discovery
Find the completed epic and gather all related stories, implementation artifacts, and review results.

### 2. Deep Story Analysis
For each completed story, extract:
- Implementation lessons and patterns discovered
- Review feedback and how it was addressed
- Technical debt introduced or resolved
- Testing strategies that worked or failed

### 3. Load Previous Retrospective
If a previous epic retrospective exists, check:
- Were action items followed through?
- Were lessons applied?
- Did process improvements take effect?

### 4. Epic Review
Discuss what went well and what presented challenges:
- Architecture decisions and their outcomes
- Tool and library choices
- Testing coverage and quality
- Code review effectiveness
- Communication and documentation quality

### 5. Next Epic Preparation
Preview the next epic (if available):
- Identify dependencies and prerequisites
- Note preparation tasks needed
- Flag potential risks or blockers

### 6. Synthesize Action Items
Create specific, actionable items:
- Each item should be SMART (Specific, Measurable, Achievable, Relevant, Time-bound)
- Assign priority levels
- Group by category (process, technical, documentation)

### 7. Save Retrospective
Save the retrospective document to: {retrospectives_folder}/epic-{epic_num}-retrospective.md
