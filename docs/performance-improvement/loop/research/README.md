# research/ — verified findings, OSS scouting, spike notes

- `verified-findings.md` — P1 output: every material claim from the reports/perf plan,
  re-confirmed (or corrected) against live code, each backed by a `../verification/` script.
- `oss-<name>.md` — one per OSS project evaluated (GNHF, firstmate, ralph-orchestrator, …):
  what it does, what we lack, what to harvest, architect's verdict, spike notes if run.
- `final-report.md` — Pf output: what shipped, measured before/after, what's parked/deferred,
  recommended next job.
